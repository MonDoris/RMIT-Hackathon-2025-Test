# ScamBaiter - Kẻ Đi Săn Bóng Ma Số (The Reverse Hacker)
**Đội thi:** Code Cơm
| **Hackathon:** RMIT GenAI & Cybersecurity Hackathon 2025 (Challenge 3)

## Giới thiệu
ScamBaiter là một tựa game web 2D mang đậm tính giáo dục và an ninh mạng. Thay vì dạy người chơi cách phòng thủ bị động (chặn tin nhắn lừa đảo), game cho phép người chơi trải nghiệm cảm giác làm một "Hacker mũ trắng", sử dụng kỹ thuật **Reverse Social Engineering** để giăng bẫy ngược lại tổ chức lừa đảo.

## Cách chạy game (How to run)
Game được viết bằng HTML, CSS, JavaScript thuần (Frontend only).
1. Clone repository này về máy.
2. Vào thư mục `game_app/`.
3. Mở file `index.html` bằng bất kỳ trình duyệt web nào (Chrome/Edge/Safari).
4. Không cần cài đặt NodeJS hay cấu hình server.

## Ý nghĩa xã hội (Social Impact)
Game nhắm trực tiếp vào vấn nạn lừa đảo người cao tuổi qua Zalo/Điện thoại đang nhức nhối tại Việt Nam. Thông qua cơ chế game, người chơi hiểu được quá trình thao túng tâm lý của tội phạm (The Greed Meter) và nhận thức được rằng kiến thức an toàn thông tin là vũ khí sắc bén nhất để bảo vệ gia đình.
